Halo, perkenalkan nama saya Sabrosa Noval Rachmadhani. Saya merupakan mahasiswa aktif S1 program studi Pendidikan Teknik Informatika dan Komputer di Universitas Sebelas Maret (UNS). Sebelum menempuh pendidikan tinggi, saya merupakan alumni dari SMA Negeri 1 Surakarta.

Saya memiliki minat yang besar di bidang pemrograman, desain, dan editing. Dalam hal pemrograman dan pengembangan, saya pernah mengerjakan tugas arsitektur website. Selain itu, saya juga aktif di sisi desain dan pengelolaan konten visual, salah satunya dengan merancang dan mengelola rencana konten media sosial untuk SAVITA, sebuah produk IoT yang berfungsi untuk memonitoring vertical garden secara real-time.

Di bidang visual, saya sangat menyukai fotografi dan videografi. Saya antusias mengeksplorasi teknik dan pengaturan kamera seperti Sony dan Canon, serta banyak melakukan proses editing tingkat lanjut menggunakan Adobe Lightroom, Premiere Pro, maupun After Effects. Di waktu luang, saya biasanya bersantai dengan memainkan game bergenre 2D action-adventure maupun run-and-gun, dengan beberapa judul favorit saya seperti Cuphead, Ori and the Blind Forest, dan Terraria.
