# Kumpulan Tugas Praktikum

Repositori ini berisi arsip tugas dan latihan dari Modul 2 hingga Modul 10.

## Daftar Tugas

| No | Modul | Materi | Deskripsi |
| :--- | :--- | :--- | :--- |
| 1 | Modul 2 | HTML | Pembuatan struktur dasar halaman web menggunakan elemen dan tag HTML. |
| 2 | Modul 3 | CSS | Pengaturan tata letak (*layout*), warna, dan tipografi menggunakan CSS dasar. |
| 3 | Modul 4 | CSS Lanjutan | Penerapan teknik CSS lanjutan seperti Flexbox/Grid, *positioning*, dan efek visual. |
| 4 | Modul 5 | Responsive Web Design (RWD) | Penerapan desain responsif agar tampilan web menyesuaikan berbagai ukuran layar. |
| 5 | Modul 6 | JavaScript | Implementasi logika pemrograman, manipulasi DOM, dan interaktivitas halaman web. |
| 6 | Modul 7 | UI/UX | Perancangan antarmuka (*User Interface*) dan pengalaman pengguna (*User Experience*). |
| 7 | Modul 8 | Bootstrap | Pengembangan halaman web responsif menggunakan komponen dan *grid system* Bootstrap. |
| 8 | Modul 9 | Web Storage | Penyimpanan dan pengelolaan data pada browser menggunakan `localStorage` / `sessionStorage`. |
| 9 | Modul 10 | Git | Penerapan *version control system* untuk pengelolaan kode dan repositori lokal maupun jarak jauh. |

## Teknologi yang Digunakan
- **Web & Styling:** HTML5, CSS3, Bootstrap
- **Scripting:** JavaScript (DOM & Web Storage)
- **Version Control:** Git
